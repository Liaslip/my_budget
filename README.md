# Спокойно — личный бюджет

Личный бюджет без сервера и обязательных ежедневных записей. Сайт работает на GitHub Pages. Планы, полученные доходы, расходы, ручные остатки счетов, накопления, цели, заметки, календарь и аналитика остаются в браузере.

## Открыть приложение

После включения Pages: https://liaslip.github.io/my_budget/

Не открывайте index.html двойным щелчком: браузер ограничивает загрузку JavaScript-модулей через file://. Открывайте опубликованный сайт или локальный HTTP-сервер.

## Первое использование и перенос бюджета

1. Откройте приложение. Новый браузер начинает с пустого бюджета.
2. Для переноса из прежнего приложения скачайте там «Данные → Скачать полную копию JSON».
3. На новом сайте выберите «Данные → Восстановить полную копию» и укажите этот файл. Восстановление заменяет текущий бюджет; сначала скачайте его копию, если он уже заполнен.
4. Добавляйте суммы, планы и счета. Изменения сохраняются в IndexedDB после завершения транзакции.

На телефоне, другом компьютере, в другом профиле браузера и по другому адресу сайта бюджет будет отдельным. Автоматической синхронизации нет. Для переноса используйте JSON-копию. Скачивайте копию регулярно и перед очисткой данных браузера. Приватный режим не предназначен для постоянного хранения.

Бюджет не загружается в GitHub или сторонние сервисы. Нет аналитических счётчиков и сетевого API; подключение JavaScript к сети запрещено Content Security Policy. Общедоступны только интерфейс и исходный код. Счета обновляются вручную; записи доходов и расходов не меняют их остатки. Инвестиции и накопления исключены из основного отчёта.

## Включение GitHub Pages

Репозиторий должен быть Public для бесплатного GitHub Pages:

1. Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: main, папка /(root) → Save.
4. Дождитесь завершения публикации и откройте адрес, показанный GitHub.

index.html лежит в корне репозитория. Все пути относительные, поэтому сайт работает в /my_budget/ и при другом имени репозитория. Сборка и установка пакетов для сайта не нужны. Файл .nojekyll отключает обработку Jekyll.

## Обновления

Изменяйте файлы в main. После успешной публикации обновите страницу. Обновления кода не заменяют сохранённый бюджет. Не загружайте в репозиторий резервные копии, базы данных, пароли и ключи.

## Проверки

Для проверок доменной модели: Node.js 24+ и команда npm test. Для проверки IndexedDB откройте tests/browser.html через HTTP и нажмите «Запустить проверки». Проверки используют отдельную временную базу, не личный бюджет.
